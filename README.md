# Campus Lost & Found with AI Assistance

SOFT3111 Internet and Web Programming term project by Sarp Onaran.

A web application that lets students and staff report items they lost or found on campus and get them back to their owners. AI suggests report details from a photo, helps report through chat, proposes areas to blur on sensitive photos, and writes verification questions for claims.

## Status

Proposal and screen design stage. The application is not built yet.
